# QR-FILE

![Flutter](https://img.shields.io/badge/Flutter-02569B?style=flat\&logo=flutter\&logoColor=white) ![Dart](https://img.shields.io/badge/Dart-0175C2?style=flat\&logo=dart\&logoColor=white) ![License](https://img.shields.io/badge/License-MIT-green)

> A cross-platform Flutter app combining **QR/Barcode scanning & generation** with **offline file sharing**. Think **Xender + QR Manager** in one lightweight utility!

![App Demo GIF](https://via.placeholder.com/800x400.png?text=App+Demo+GIF)

---

## ⚡ Features

### QR & Barcode

* Scan QR codes & barcodes with camera.
* Categorize scans: URLs, Wi-Fi, contacts, products.
* Generate QR codes for text, Wi-Fi, vCards, or file-sharing setup.
* Quick search, favorites, and organized history.

### File Sharing

* Offline peer-to-peer transfer via **Wi-Fi Direct** & **Bluetooth**.
* Supports all file types: images, videos, audio, docs, archives.
* Bulk transfer with drag-and-drop selection.
* Transfer history with timestamps.

### Integration & Utilities

* QR pairing for faster device connections.
* App themes: light/dark/system.
* Security: app lock, hidden folders.
* Data management: clear cache/history.
